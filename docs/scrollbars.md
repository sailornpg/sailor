# 应用滚动条

统一使用 10px 轨道、2px 内边距和圆角滑块，颜色来自主题变量，悬停提高对比度。

`components/ui/scroll-area.tsx` 基于 shadcn new-york-v4 官方源码，复用已有 radix-ui 和项目 cn，提供横纵两个方向，不新增依赖。

| 区域 | 实现 |
| --- | --- |
| 文件树、模型设置内容 | ScrollArea；分栏尺寸和设置底部保存栏保持原布局 |
| 聊天 | 保留 assistant-ui Viewport，维持自动跟随和定位 |
| CodeMirror | 保留编辑器 scroller 和固定行号栏 |
| 侧栏、外观设置、菜单、代码块、表格、输入框 | 原生滚动，统一 CSS 外观 |
| 原已隐藏滚动条的导航区域 | 保留隐藏策略 |

globals.css 的 base layer 定义 Chromium 原生滚动条样式，组件共享 --scrollbar-* 变量。低优先级样式允许 Radix Viewport 隐藏原生条，避免双重滚动条。聊天与编辑器不新增嵌套滚动容器。
